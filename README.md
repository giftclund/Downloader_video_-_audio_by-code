README — Downloader M&V

Este projeto possui dois arquivos diferentes, cada um desenvolvido para uma plataforma específica:

- "downloader M&V.sh" → Android / Termux
- "downloader.bat" → PC / Windows

«⚠️ IMPORTANTE: Os arquivos não são intercambiáveis. Cada um foi desenvolvido para uma arquitetura/ambiente específico.»

---

📱 Downloader M&V — Termux

Arquivo

downloader M&V.sh

Compatibilidade

Este arquivo foi desenvolvido exclusivamente para Termux no Android.

«❌ Não tente executar o "downloader M&V.sh" em um PC. Ele não foi desenvolvido para funcionar em computadores.»

📦 Coisas necessárias

- Termux
- FFmpeg
- FFprobe
- yt-dlp

▶️ Como usar

Passo 1 — Abrir o Termux

Abra o aplicativo Termux no Android.

Passo 2 — Instalar as dependências necessárias

Instale:

- FFmpeg
- FFprobe
- yt-dlp

Passo 3 — Limpar o terminal

Este passo é opcional.

clear

Passo 4 — Executar o arquivo

Cole o seguinte comando no Termux:

bash ~/downloader\ M\&V.sh

«As barras "\" são necessárias porque o nome do arquivo possui espaços e o caractere "&".»

---

💻 Downloader M&V — PC

Arquivo

downloader.bat

Compatibilidade

Este arquivo foi desenvolvido pensando na arquitetura de PCs com Windows.

«❌ Não tente executar o "downloader.bat" no Termux. Ele foi desenvolvido para PC e não funciona no ambiente do Termux.»

📦 Coisas necessárias

- Um PC
- FFmpeg
- FFprobe
- yt-dlp

▶️ Como usar

Passo 1 — Baixar o arquivo

Baixe o arquivo:

downloader.bat

Passo 2 — Baixar as dependências

Instale ou disponibilize no PC:

- FFmpeg
- FFprobe
- yt-dlp

Passo 3 — Executar o arquivo

Clique no arquivo "downloader.bat" para executá-lo.

💡 Opcional — Criar um atalho

Você pode criar um atalho do "downloader.bat" para facilitar o acesso.

Também é possível personalizar o atalho colocando um ícone nele.

Passo 4 — Utilizar o arquivo

Depois de executar o arquivo, basta seguir as instruções apresentadas pelo próprio programa.
